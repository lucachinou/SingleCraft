# SingleCraft - Beta Version

**Currently working on datapack management**

**SingleCraft is a powerful and lightweight Minecraft server manager.**
*Note: SingleCraft is still in beta and doesn't have all the planned features!*

*Currently not secure as it can be (Because of missing robust permissions system)*

## Installation
1. Download Python 3.11 if you don't have it already
2. Run `pip install -r requirements.txt` in the terminal to install the required dependencies
3. Run `python SingleCraft.py` to start the web server.
4. Open your browser and navigate to `http://localhost:5000` to access the SingleCraft dashboard.

## Known Issues
- The clear console function does not clear the console properly.

## Features
* Create and manage multiple Minecraft servers from a single interface.
* Start, stop, and restart servers with ease.
* View server logs in real-time.
* User authentication and role-based access control.
* Support for various Minecraft server types (e.g., Spigot, Paper, Vanilla).
* Regular updates and new features based on user feedback.

## Goals
* Provide a user-friendly interface for managing Minecraft servers.
* Ensure high performance and reliability for server management.
* Backup system and scheduled tasks for server maintenance.
* Expand compatibility with more Minecraft server types and plugins (e.g. BungeeCord, Velocity, Fabric, Forge, ...).
